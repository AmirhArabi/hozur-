# ثبت ساعت کاری (Work Tracker)

اپلیکیشن موبایل فارسی و راست‌به‌چپ (RTL) برای ثبت، مدیریت و محاسبه دقیق ساعات کاری، مرخصی و اضافه‌کار با تقویم شمسی و ذخیره‌سازی محلی روی دستگاه.

این پروژه به‌صورت وباپ با **React 19 + TypeScript + Vite** نوشته شده و با استفاده از **Capacitor** به یک اپلیکیشن بومی اندروید تبدیل می‌شود. تمامی داده‌ها منحصراً روی حافظه محلی دستگاه کاربر (با استفاده از `@capacitor/preferences` و پشتیبان محلی IndexedDB) ذخیره می‌گردند و به هیچ سرور خارجی یا ثبت‌نامی وابسته نیست.

---

## ویژگی‌های اصلی

1. **طراحی مینیمال و متریال تکرنگ (Monochromatic)**:
   - صرفاً با رنگ‌های سیاه، سفید و طیف‌های خاکستری (بدون هیچ رنگ فانتزی دیگر).
   - تفکیک وضعیت‌ها از طریق ضخامت خطوط، وزن فونت و پر/توخالی بودن نشانه‌ها.
   - پشتیبانی از تم تاریک (Dark Mode) و تم روشن (Light Mode).
   - فونت محلی وزیرمتن (Vazirmatn) بدون نیاز به اینترنت و بدون اتصال به CDN.
   - اندازه لمسی المان‌ها حداقل ۴۸ پیکسل مطابق اصول ارگونومی موبایل.

2. **تب ثبت (Record)**:
   - نمایش تاریخ شمسی و روز هفته.
   - کارت‌های زنده: کارکرد امروز (زمان‌سنج زنده با ثانیه‌شمار برای بازه فعال)، مانده تا سقف موظفی، ساعت تخمینی خروج و اضافه‌کار روز.
   - دکمه تک‌لمسی «شروع کار / پایان کار» سریع.
   - امکان ثبت چندین بازه کاری در روز به همراه دکمه‌های «ثبت همین لحظه».
   - ثبت مرخصی ساعتی و مرخصی تمام‌روز.
   - اعتبارسنجی خودکار عدم همپوشانی بازه‌ها و تقدم شروع بر پایان.
   - تقویم شمسی برای جابه‌جایی سریع بین روزها و ویرایش گذشته.

3. **تب آمار (Statistics)**:
   - ۷ کارت آماری تحلیلی ماه: مجموع ساعات کاری (P + H)، روزهای دارای کارکرد، موظفی کل ماه (D)، مانده تا موظفی، ساعات مرخصی (L)، روزهای دارای مرخصی، و اضافه‌کار کل.
   - تقویم ماهانه شمسی با نشانه‌های تکرنگ مجزا (امروز، دارای کارکرد، دارای مرخصی، دارای اضافه‌کار، تعطیلات رسمی و تعطیلات هفتگی).
   - لمس هر روز برای باز کردن جزئیات کامل و امکان پرش به ویرایش آن روز.
   - خروجی جدول ماه به فرمت CSV سازگار با اکسل (با انکودینگ UTF-8 BOM جهت پشتیبانی از حروف فارسی).

4. **تب تنظیمات (Settings)**:
   - تعیین ساعت موظفی روزانه (پیش‌فرض: ۸ ساعت و ۳۰ دقیقه).
   - تنظیم تعطیلات هفتگی (جمعه ثابت، پنج‌شنبه اختیاری).
   - مدیریت تعطیلات رسمی با تعطیلات ثابت تقویم شمسی بارگذاری‌شده به همراه قابلیت افزودن و حذف تعطیلات سالانه و مناسبتی دلخواه.
   - یادآوری ثبت خروج (با درخواست مجوز اعلان `POST_NOTIFICATIONS` در اندروید ۱۳ به بالا).
   - پشتیبان‌گیری کامل در قالب فایل JSON و بازیابی آن.

5. **منطق محاسباتی دقیق**:
   - $D = \text{موظفی روزانه} \times \text{تعداد روزهای موظفی}$
   - $P = \text{ساعات کارکرد در روزهای موظفی}$
   - $L = \text{ساعات مرخصی}$
   - $H = \text{ساعات کار در روزهای تعطیل (۱۰۰٪ اضافه‌کار)}$
   - $\text{مانده تا موظفی} = \max(0, D - P - L)$
   - $\text{اضافه‌کار عادی} = \max(0, P - D)$
   - $\text{اضافه‌کار کل} = \text{اضافه‌کار عادی} + H$
   - محاسبه روزانه اضافه‌کار بر مبنای توالی زمانی روزها و نرخ رشد اضافه‌کار انباشته ماه.

## تولید آیکون‌ها برای اندروید

یک آیکون تکرنگ با کیفیت در مسیر `assets/icon.png` قرار داده شده است. برای تولید خودکار تمامی اندازه‌های آیکون برای اندروید (mipmap-xxxhdpi و...) دستور زیر را اجرا کنید:

```bash
# نصب ابزار تولید دارایی‌های Capacitor (در صورت نیاز)
npm install -D @capacitor/assets

# تولید آیکون‌ها برای پروژه اندروید
npx @capacitor/assets generate --android
```

## اسکریپت‌های پروژه

- **اجرای تست‌های محاسبات و تقویم**:
  ```bash
  npm test
  ```
- **ساخت نسخه وب**:
  ```bash
  npm run build
  ```
- **همگام‌سازی با پروژه اندروید**:
  ```bash
  npm run cap:sync
  ```
- **اجرای سرور توسعه**:
  ```bash
  npm run dev
  ```

## ساخت فایل نصبی APK با GitHub Actions

فایل گردش کار در مسیر `.github/workflows/build-apk.yml` قرار دارد:
- با هر `push` به شاخه `main` و همچنین به‌صورت دستی (`workflow_dispatch`) از تب Actions در گیت‌هاب اجرا می‌شود.
- از محیط `ubuntu-latest` با **Node.js 20** و **Java JDK 21 (Temurin)** مطابق پیش‌نیاز نسخه Capacitor استفاده می‌کند.
- مراحل شامل: اجرای تست‌ها، بیلد وب، اضافه کردن بستر اندروید، اجرای `./gradlew assembleDebug` و در نهایت آپلود فایل APK در قالب Artifact قابل دانلود می‌باشد.
